# WEEKFORM Studio — 週間スケジュールメーカー

VTuber・歌い手・配信者向けの週間スケジュール画像を作成できるツールです。
予定・配色・文字・立ち絵・ロゴを編集し、PNG画像として保存できます。

HTML・CSS・JavaScriptを1つのHTMLファイルにまとめているため、ダウンロードしてブラウザで開くだけで使えます。Java・JDK・WSLのインストールや、サーバーの起動は不要です。

## 主な機能

- 月曜日〜日曜日の予定、時間、タイトル、活動名義、開始日を編集
- 4種類の画像比率に対応：1:1 / 16:9 / 4:5 / 9:16
- 5種類のレイアウトと4種類の予定枠を選択
- ランダム配置・カスタム配置、配色の再生成・濃さの調整
- 文字のフォント・色・サイズ・太字・縁取りを設定
- 各日の予定枠に最大6枚の画像を追加
- 複数の立ち絵・ロゴを追加し、位置・大きさ・透明度・重なり順を調整
- 画像の表示範囲を指定して切り取り
- 背景画像、チェック・ストライプ・ドット柄、31種類のモチーフを設定
- 外枠・角飾りのカスタマイズ
- X / YouTube / ツイキャス / TikTok / Twitch / BiliBiliのアイコンを表示
- PNG出力、画像を含む設定JSONの保存・読み込み

## 使い方

1. このリポジトリの「Code」→「Download ZIP」からダウンロードし、ZIPを解凍します。
2. `Weekly_Schedule_Maker.html` をブラウザで開きます。
3. タイトル・活動名義・開始日・各日の予定を入力します。
4. 配色や文字を調整し、必要に応じて立ち絵・ロゴ・背景画像を追加します。
5. プレビューを確認して「PNGを保存 ↓」を押します。

作業を後から再開したい場合は、「設定JSONを保存」で設定を書き出してください。「設定を読み込み」から保存したJSONを読み込めます。

## 出力サイズ

| 比率 | サイズ |
| --- | --- |
| 1:1 | 1080 × 1080 px |
| 16:9 | 1920 × 1080 px |
| 4:5 | 1080 × 1350 px |
| 9:16 | 1080 × 1920 px |

出力形式はPNGです。プレビューに表示される青い選択枠は、保存画像には入りません。

## 画像・設定の取り扱い

読み込んだ画像や設定は、利用者のブラウザ内で処理します。
本ツールには、画像や設定を外部サーバーに送信する機能や、AI学習用に収集・提供する機能はありません。外部ライブラリや外部フォントの読み込みもありません。

保存する設定JSONには、追加した画像も含まれます。JSONを他の人に渡す場合は、含まれる画像も一緒に共有されることにご注意ください。

## 補足

- 読み込める画像形式：PNG / JPEG / WebP
- 時間：1行5文字・最大2行
- 予定内容：1行26文字・最大2行
- フォントの表示は、利用端末にインストールされているフォントによって変わります。
- 大きな画像を多数追加すると、処理や設定JSONの保存に時間がかかる場合があります。
- 使用するイラスト・ロゴなどは、それぞれの利用条件に従ってください。
